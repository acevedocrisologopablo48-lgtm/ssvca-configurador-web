# Bajantes del plano general

Restitución del receptor abierto C01 con las diez piezas nativas del catálogo original, trasladadas sobre la máquina BAK sin escalar. Campanas abiertas de tres caras sobre tambor, receptor inferior separado y codos de sección reducida según isométrica original. G01 colecta únicamente la zona de barras, dentro de su cuerpo, y conecta con F02 mediante sección uniforme. Máquinas, posiciones y descarga directa G01-J01 conservadas. Ajuste de interfaces estimado, no fabricación.
