# Detalle exterior de equipos y estructuras

Revisión máquina por máquina sobre revision760. Detalles visibles de cojinetes, uniones, asientos, bridas, anclajes y testeros. Se conservan las posiciones, alturas, apoyos, longitudes, secciones de acero, puertos y bajantes aprobados. Las fijaciones y pequeños detalles sin cota son aproximaciones visuales identificadas en las recetas; no añaden precisión de fabricación. Piezas repetidas comparten geometría y conservan sus asociaciones paramétricas.
