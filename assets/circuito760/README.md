# Original 760 · Circuito corregido

Referencia independiente. Los planos y catálogos anteriores permanecen intactos.

- Rechazo de primera malla: S01 → J02 → F03 → C01 → F02 → S01.
- Retenido en segunda malla: S01 → F03 → C01 → F02 → S01.
- Pasante de ambas mallas: colector S01 → H01 → F04.

Mallas de 25,4 y 12,7 mm. Alambre de 2 mm como estimación visual. Motor del cono sobre plataforma conectada al bastidor; G01 con bandeja y parrilla continua, ménsulas de resortes conectadas; S01 con excitador compacto entre pisos; J01 con volantes aligerados y detalle de carcasas y fijaciones. Se mantienen máquinas, emplazamiento, altura superior y longitudes/polines de las fajas.

Las geometrías de detalle no acotadas, colector, bajantes y montaje estructural son adaptaciones estimadas de configuración, no cálculo de fabricación. Funcionamiento contrastado con https://www.mclanahan.com/products/vibrating-grizzly-feeders y https://www.metso.com/portfolio/csh-series-screens/; medidas de los BAK locales.
